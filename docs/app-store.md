## Datenschutzangaben im Fragebogen

„Es werden keine Daten erfasst.“ Die Schreibmaschine sendet nichts an eigene oder fremde Server. Die Berechtigung für ausgehende Netzwerkverbindungen (`com.apple.security.network.client`) hat sie nur, weil die Webansicht (WebKit) der Markdown-Vorschau ohne sie in der Sandbox nicht startet; die Vorschau lädt nichts aus dem Netz. Einstellungen, Sitzung, ungesicherte Texte und der Zustand pro Datei liegen ausschließlich lokal im Container der App. Eigene Skripte des Nutzers laufen auf seinem Mac und gehören nicht zur App. Käufe wickelt Apple ab.

Dieselbe Aussage steht maschinenlesbar in `Resources/PrivacyInfo.xcprivacy`: kein Tracking, keine Tracking-Domains, keine erfassten Datentypen.

## Hinweise für die Prüfung

Die Schreibmaschine ist ein Texteditor. Es gibt keine Anmeldung, kein Konto und keine Testzugangsdaten. Dateien ändert die App nur, wenn man sie ausdrücklich sichert (⌘S); ungesicherte Texte hält sie in ihrem Container, damit beim Beenden nichts verloren geht.

Die drei In-App-Käufe sind freiwillige Trinkgelder für die Weiterentwicklung. Sie schalten keine Funktionen frei; alle Funktionen sind ohne Kauf verfügbar. Zu finden sind sie unter „Schreibmaschine → Über Schreibmaschine“ und „Hilfe → Schreibmaschine unterstützen …“.

Berechtigungen:
- `com.apple.security.network.client` braucht allein die Markdown-Vorschau: Sie zeigt das HTML in einer WKWebView, deren Hilfsprozesse in einer sandboxierten App ohne diese Berechtigung nicht starten. Eine Content-Security-Policy verbietet der Seite jeden Netzzugriff; Links öffnen im Browser.
- `com.apple.security.files.user-selected.read-write` zum Öffnen und Sichern der Dateien, die der Nutzer wählt.
- `com.apple.security.files.bookmarks.app-scope`, damit die Sitzung beim nächsten Start die zuletzt offenen Dateien wieder öffnen kann, nur Dateien, die der Nutzer selbst geöffnet hat.

Eigene Skripte: Das Menü „Skripte“ zeigt ausführbare Dateien aus dem Ordner, den macOS für die Skripte der App vorsieht (`~/Library/Application Scripts/com.stefanradermacher.schreibmaschine`), und führt sie über `NSUserUnixTask` aus, nur auf Befehl des Nutzers. Die App selbst bringt keine Skripte mit; „Beispielskripte installieren …“ schreibt drei kleine Shell-Beispiele erst dann in den Ordner, wenn der Nutzer ihn in einem Öffnen-Dialog bestätigt.

Die Schreibmaschine fragt an seltenen Stellen, ob sie die Standard-App für Text und Code werden soll. Die Frage erscheint als schmale Leiste unter der Titelleiste, erst nachdem die App an drei verschiedenen Tagen benutzt wurde, höchstens zweimal insgesamt, und die eigentliche Umstellung bestätigt macOS selbst. In den Einstellungen lässt sie sich jederzeit zurücksetzen.

Zum Testen eignet sich jede beliebige Textdatei; das Handbuch öffnet „Hilfe → Schreibmaschine-Handbuch“.

**English** (für das Feld „Notizen“ unter „Informationen zur App-Prüfung“; die Prüfer arbeiten meist mit englischer Oberfläche):

Schreibmaschine is a text editor. There is no sign-in, no account and no demo credentials. The app changes files only when the user explicitly saves them (⌘S); it keeps unsaved texts in its container so that nothing is lost on quitting.

The three in-app purchases are voluntary tips for further development. They do not unlock any features; everything is available without a purchase. They can be found under “Schreibmaschine → About Schreibmaschine” and “Help → Support Schreibmaschine…”.

Entitlements:
- `com.apple.security.network.client` is needed only by the Markdown preview: it shows the HTML in a WKWebView, whose helper processes do not start in a sandboxed app without this entitlement. A content security policy forbids the page any network access; links open in the browser.
- `com.apple.security.files.user-selected.read-write` to open and save the files the user chooses.
- `com.apple.security.files.bookmarks.app-scope` so that the session can reopen the files that were last open on the next launch, only files the user opened.

Scripts of your own: the Scripts menu lists executable files from the folder macOS provides for the app's scripts (`~/Library/Application Scripts/com.stefanradermacher.schreibmaschine`) and runs them through `NSUserUnixTask`, only when the user chooses one. The app itself ships no scripts; “Install Example Scripts…” writes three small shell examples into the folder only after the user confirms it in an open panel.

On rare occasions, Schreibmaschine asks whether it should become the default app for text and code. The question appears as a slim bar below the title bar, only after the app has been used on three different days, at most twice in total, and macOS itself confirms the actual change. It can be reset in the settings at any time.

Any text file is suitable for testing; “Help → Schreibmaschine Manual” opens the manual.

## TestFlight

Für interne Tester (Mitglieder des Entwicklerkontos) genügen der App-Eintrag und ein hochgeladener Build; Apple prüft nichts, und die Frage nach der Verschlüsselung entfällt, weil `ITSAppUsesNonExemptEncryption = false` in der Info.plist steht.

Unter „TestFlight → Testinformationen“ werden dann gebraucht: eine Beta-Beschreibung (der Werbetext reicht), eine E-Mail-Adresse für Rückmeldungen (schreibmaschine@stefanradermacher.com), die Datenschutz-URL und die Hinweise für die Prüfung von oben. ## Einreichen

Die Reihenfolge ist wichtig, weil der erste Verbrauchsartikel nur zusammen mit einer App-Version geprüft wird:

1. Auf der Versionsseite den Build auswählen und „Zur Prüfung hinzufügen“. Das legt einen Übermittlungsentwurf an. Dafür müssen unter „App-Informationen“ Kategorie und Inhaltsrechte gesetzt sein.
2. Auf der Seite jedes In-App-Kaufs „Zur Prüfung hinzufügen“. Sein Status „In Vorbereitung zur Übermittlung“ ist dabei normal.
3. Im Entwurf prüfen, dass Version und alle Käufe enthalten sind, dann „Zur Prüfung übermitteln“.
